Mise en route

Comment l'installer ?

Ajoute Orienty en moins de deux minutes dans ton client.

🤖

Claude Desktop

claude_desktop_config.json

Ouvre le fichier de configuration de Claude Desktop (accessible via Paramètres > Développeur > Edit Config) et colle ce bloc :

{
  "mcpServers": {
    "orienty": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://orienty-mcp.ton-domaine.workers.dev/mcp"
      ]
    }
  }
}

💡 Redémarre Claude Desktop : l'icône marteau 🔨 confirmera la disponibilité immédiate des 10 outils Orienty.

💻

Cursor / Windsurf / IDE

Settings > Features > MCP

Ajoute un nouveau serveur MCP distant directement depuis les réglages de ton éditeur :

Type SSE / Remote HTTP
Nom orienty
URL https://orienty-mcp.orienty.workers.dev/mcp

Aucun compte n'est requis. Notre infrastructure Cloudflare applique automatiquement une protection de quota par IP.

Capacités

10 outils natifs inclus

Voici ce que ton assistant IA peut exécuter en temps réel :

searchJpos

Portes ouvertes & salons

Trouve les prochaines sessions JPO par établissement, commune ou département.

getSchoolJpoDetails

Détails d'un établissement

Récupère les dates d'accueil précises et coordonnées à partir du nom ou code UAI.

searchMentors

Mentors étudiants

Filtre les étudiants de la communauté Orienty par filière, école et compétences.

getMentorProfile

Profil public complet

Affiche le cursus détaillé, les centres d'intérêt et le lien de contact d'un mentor.

getCommunityStats

Stats de communauté

Fournit le volume d'étudiants vérifiés inscrits par filière d'études.

searchSchools

Annuaire des écoles

Explore lycées publics/privés, universités françaises et universités internationales.

searchFormations

Catalogue des formations

Recherche croisée des cursus, diplômes et fiches Onisep / Parcoursup.

getFormationLocations

Lieux d'enseignement

Cartographie tous les établissements dispensant une formation spécifique.

getPathwayStats

Origine des Bacs

Pourcentages de bacs (général, techno, pro) observés chez les admis.
